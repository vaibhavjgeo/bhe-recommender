§ About this project

What is the BHE Recommender?

An interactive feasibility tool for shallow geothermal heat pumps in Germany. Click anywhere on the map to see the sustainable heat-extraction rate at that exact location, then get a recommended borehole depth, expected sustainable output, full cost breakdown, and a downloadable PDF report. All values are grounded in my Master's thesis at KIT - 5 km resolution data from 8 CMIP6 climate models under two emission scenarios.

§ How it works

From a map click to a complete report.

Four steps from picking a site to downloading a multi-page PDF for any location in Germany.

→ 01 / PICK

Click a site

Click anywhere on the map. The tool reads the sustainable heat-extraction rate (W/m) from the thesis raster at that pixel.

→ 02 / CONFIGURE

Set parameters

Enter heating demand (kW), optional budget, and whether you want cooling or hot water on top of heating.

→ 03 / CALCULATE

Get the numbers

The backend computes recommended depth, sustainable output, and a full German-market cost breakdown.

→ 04 / EXPORT

Download PDF

Gemini writes a personalized site interpretation. Download the full multi-page report for your records.

§ Tech stack

Real data, real tools.

Pre-computed thesis data + serverless compute + AI interpretation, all running for free.

Data

4 pre-computed JSON files from my thesis (2 SSP scenarios × 2 ensemble statistics), 5 km resolution across Germany.

Frontend

Vanilla HTML / CSS / JS, Leaflet maps with custom pixel rendering via chroma-js, jsPDF for client-side reports.

Backend & AI

Vercel serverless functions handle depth and cost calculations. Google Gemini writes site interpretations.

Hosting

Vercel free tier with GitHub auto-deploy. Total infrastructure cost: €0 / month.

Development

AI-pair-programming with Anthropic Claude, ChatGPT, and GitHub Copilot. Architecture and review by me.

§ How this was built

Built with AI as a pair-programmer.

Anthropic Claude was my primary pair-programmer for the Leaflet click-to-query interaction, the cost model logic, the jsPDF client-side report generation, and the Vercel serverless function for AI interpretation. ChatGPT helped iterate on the cost model assumptions (German market price ranges). GitHub Copilot handled inline suggestions. I designed the product idea (turning thesis data into a homeowner-facing tool), the cost model structure, the disclaimer wording, the choice of client-side PDF generation, and I reviewed every line before deployment. The thesis data underlying this app was produced by my Python notebook (also AI-assisted). This tool turns that data into something a homeowner can use.
